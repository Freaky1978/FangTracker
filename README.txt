FangTracker PWA – persönliche iPhone Fangbuch-App

WICHTIG:
Für Kamera, GPS und Installation als Web-App sollte FangTracker über HTTPS geöffnet werden. Nur die Dateien direkt auf dem iPhone zu öffnen reicht nicht zuverlässig.

Enthalten:
- Fang mit Foto erfassen
- Fischart, Gewässer, Länge, Gewicht, Köder, Methode, Notizen
- optionale GPS-Position
- Fangbuch + Suche
- Statistik / Rekorde
- gespeicherte Position in Apple Karten öffnen
- Offline-Grundfunktion über Service Worker
- lokale Speicherung im Browser des iPhones

Installation auf iPhone nach Bereitstellung über HTTPS:
1. FangTracker-URL in Safari öffnen.
2. Teilen-Symbol antippen.
3. „Zum Home-Bildschirm“ wählen.
4. „Hinzufügen“ antippen.

Hinweis: Browserdaten/Safari-Websitedaten nicht löschen, solange die Fänge nur lokal gespeichert sind. Eine spätere Version kann Backup/Export erhalten.
